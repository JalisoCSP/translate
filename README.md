Simple website built in in Jekyll for simple terms when traveling:
* Hello
* Goodbye
* Thanks
* Sorry

https://determined-spence-153aaf.netlify.app/

## Steps to use
- Create a new repo, using this one as the template.
- Run `bundle install` (might need to run `gem install bundler` first)
- Run `yarn install`
- Run `jekyll serve`
- Continue development
